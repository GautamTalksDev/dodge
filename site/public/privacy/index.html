Privacy

No accounts. No cookies.

DODGE is a static website. It has no sign-in, no forms, no cookies and no advertising. Here is everything that happens when you visit.

What your browser loads

  • This site (HTML, CSS, JavaScript, fonts) from Cloudflare, which hosts it. Cloudflare processes your IP address to deliver the page, as every web host does.
  • The daily data from raw.githubusercontent.com, run by GitHub. Your browser asks GitHub for the files directly, so GitHub also sees your IP address. See GitHub's privacy statement.

Analytics

Cloudflare Web Analytics counts page views. It sets no cookies, uses no local storage and does not fingerprint visitors. See Cloudflare Web Analytics.

What DODGE stores about you

Nothing. There is no database and no server-side code.

Links that leave the site

"Post" buttons open X with prefilled text. Nothing is sent until you choose to post it there.
